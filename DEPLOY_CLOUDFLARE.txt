PUBLICAR O ACORD NO CLOUDFLARE — SEM USAR SEU PC COMO SERVIDOR

Você pode fazer a publicação inteira usando GitHub + painel da Cloudflare.
Depois de publicado, seu computador pode ficar desligado.

1. CRIE/USE UM REPOSITÓRIO NO GITHUB
Extraia este ZIP.
Coloque na raiz do repositório estes arquivos/pastas:
- src/
- public/
- package.json
- wrangler.jsonc
- .gitignore
- README.txt
- DEPLOY_CLOUDFLARE.txt
- MIGRACAO.txt

Não coloque o server.js antigo junto desta versão.

2. ABRA A CLOUDFLARE
https://dash.cloudflare.com/

3. ENTRE EM
Workers & Pages

4. CLIQUE
Create application

5. ESCOLHA
GitHub

6. AUTORIZE O GITHUB E SELECIONE O REPOSITÓRIO DO ACORD

7. NOME DO WORKER
Use:
acord

O arquivo wrangler.jsonc também usa "name": "acord".
O nome no painel e no wrangler precisam coincidir.

Se já existir um Worker chamado acord na sua conta:
- escolha outro nome no painel;
- altere também a propriedade "name" em wrangler.jsonc para o mesmo nome.

8. BUILD
Este projeto não precisa compilar frontend.

Build command:
deixe em branco.

Deploy command:
npx wrangler deploy

O Workers Builds normalmente já usa npx wrangler deploy como padrão.

9. CLIQUE EM SAVE AND DEPLOY

O primeiro deploy cria automaticamente o Durable Object SQLite definido em wrangler.jsonc.

10. ENDEREÇO
Depois do deploy, a Cloudflare mostrará um endereço parecido com:
https://acord.SEUSUBDOMINIO.workers.dev

Esse é o endereço público do Acord.

11. TESTE
Abra:
https://SEU-ENDERECO.workers.dev/health

Deve aparecer JSON contendo, entre outros:
"ok": true
"platform": "cloudflare-workers"
"realtime": "durable-objects-websocket"
"storage": "durable-object-sqlite"

12. TURN OPCIONAL PARA CALLS
Se futuramente você tiver um servidor TURN:
Worker > Settings > Variables and Secrets

Adicione:
TURN_URLS
TURN_USERNAME
TURN_CREDENTIAL

Não é obrigatório para chat/login/servidores.
É apenas para melhorar WebRTC em algumas redes restritivas.

13. ATUALIZAÇÕES
Depois de conectar o GitHub ao Worker:
cada push na branch configurada pode disparar um novo deploy automaticamente.

IMPORTANTE
- Não precisa abrir porta no roteador.
- Não precisa Cloudflare Tunnel.
- Não precisa deixar computador ligado.
- Não precisa Render.
- Não precisa banco PostgreSQL separado.
- Não precisa pagar hospedagem enquanto permanecer dentro do Workers Free.

Se o plano gratuito atingir seus limites diários, operações daquele tipo podem falhar
até a franquia ser renovada; a Cloudflare não transforma isso automaticamente em cobrança
no Workers Free.
